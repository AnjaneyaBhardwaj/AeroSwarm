## Findings

Hand-written (session 15, 2026-10-15); `scripts/of_validate.py report` keeps this section.

1. **The tier reproduces the NACA 0012 reference within 1.3% in Cl and 11% in Cd** at alpha 10 (Cl 1.0916 vs
   1.078, Cd 0.0138 vs 0.0124). Residuals fall 7-8 orders; 2.5-3.5 min per case on one core. How the setup was
   reached (alpha 10, same mesh family unless stated):

   | change | Cl | Cd |
   |---|---|---|
   | 30 c far field, 0.7% c blunt TE | 1.0961 | 0.01664 |
   | 0.2% c TE (the reference airfoil is sharp) | 1.0801 | 0.01590 |
   | + 100 c far field | 1.0919 | 0.01376 |
   | + 360 cells around (instead of 240) | 1.0908 | 0.01364 |
   | + first-order k / omega convection (adopted) | 1.0921 | 0.01372 |

   The far field carries most of the drag error (the remaining excess is pressure drag; skin friction 0.0059).
   A 300 c far field diverged in the pressure solve (cells too large far out): a recovery-ladder case for part 2.
2. **At the project's Re 3e5, fully turbulent SST and XFoil disagree far beyond the 0.1 fidelity-gap check.**
   The session-12 witness (target Cl -1.83): OpenFOAM -1.44 with Cd 0.0436 and TE separation from x/c 0.71;
   XFoil -1.82, Cd 0.0225, attached. Less loaded designs agree better (Cl ratio 0.85-0.87, Cd 1.7x). The mesh
   and convergence are clean (y+ < 0.5, residuals down 7 orders), so this is model form: at Re 3e5 the boundary
   layer is laminar over much of the chord (XFoil transition ~0.4 c with a laminar bubble), and a fully turbulent
   boundary layer separates earlier under the same adverse gradient. **Next step: the transition model
   `kOmegaSSTLM` (Langtry-Menter gamma-Re_theta), available in this v1912 build.** Until then T2 should not be a
   terminal fidelity for the hard preset.
3. **v1912 package issues, worked around:** every function object (forceCoeffs, yPlus) aborts with an "sha1"
   IOstream error, so forces, y+, Cp and Cf come from the written fields; GAMG diverges on this mesh in the first
   pressure solve, so p uses PCG/DIC; second-order omega convection keeps omega bounded in every iteration (no
   effect on the forces), so k and omega are first order.
4. **Mesh:** a structured O-grid written directly as polyMesh (no snappyHexMesh), self-repairing near the wall
   and radial (fold-proof) once a layer is star-shaped. Every FSAE-legal corner of the camber / position /
   thickness box meshes with max non-orthogonality < 60 deg; one FSAE-illegal extreme (m 0.09 at 0.2 c,
   t 0.08) fails checkMesh (90 deg): a re-mesh case for the recovery ladder.
